# Persona portraits

The Clinic View composites Vorty's head (`../vorty-face-no-headphones.svg`)
with one accessory from `../accessories/animated/`. The filename stored on
the persona (`headset.svg`, `beanie.svg`, …) is that overlay. `none` is the
bare face.

The SVG files in this folder are leftover full-body placeholders and are
not shown on the picker any more.
