How to run it

# every default model with a key, all scenarios
make bench
# two models, pass^3, one problem
make bench MODELS=helmcode/qwen3.6,helmcode/deepseek-v4-flash K=3 ONLY=p4.
# keep it: push the run to the bench-results branch (this page reads it)
make bench-publish
# tell the team
make bench-discord

Candidates and prices live in evals/bench/models.yaml. The policy behind the recommendation is in evals/bench/runner.py, function recommend. The GitHub Actions workflow bench runs it on a schedule and on every change to the prompt or the tools. Details: docs/evals.md.
