# Vortex — HackSpain 2026

Team **Vortex**. Track: **Prosper AI** (`prosper-ai`).

## The challenge

Build a voice AI agent that answers inbound scheduling calls for a clinic.
The agent identifies the caller, looks them up in the clinic records, finds
real availability, and books, moves or cancels the appointment. Some calls
must not end in a booking. The agent must refuse for the right reason and
say so. Silence always fails the case.

Full brief: https://hackspain.app/tracks/prosper-ai

## Scoring

- **Leaderboard** — automatic. After each call the agent reports what it did.
  The report matches the case, or the case fails. There is no partial credit.
- **Jury** — the call quality, the orchestration, the live visibility, and the
  evidence that the system works.
